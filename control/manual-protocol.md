# Ручные контрольные сценарии

Встроенные браузеры мессенджеров нельзя запустить из Playwright, поэтому эти сценарии выполняются руками на реальных устройствах. Они проверяют два критерия: связь уведомления с сессией и сохранение метки. Интервал здесь не оценивается: момент нажатия рукой нельзя записать с точностью до секунды.

## Подготовка

1. Сайт развёрнут и доступен по публичному адресу.
2. Для каждого сценария из таблицы собрать ссылку: `https://<адрес>/<страница>?utm_source=<source>&utm_medium=<medium>&utm_campaign=manual_<номер>&nv_scn=manual-<номер>&nv_nav=1`.
3. В поле email вводить `manual-<номер>@control.navil.test`. По этому адресу заявка находится в базе и исключается из отчётов воронки.

## Сценарии

| №   | Устройство и приложение        | Действие                                                                             | Ожидаемая метка               |
| --- | ------------------------------ | ------------------------------------------------------------------------------------ | ----------------------------- |
| M01 | iPhone, Telegram               | ссылка в чате → встроенный браузер → отправить форму                                 | telegram / chat               |
| M02 | iPhone, Telegram               | ссылка в чате → «Открыть в Safari» до заполнения → отправить форму                   | telegram / chat               |
| M03 | iPhone, WhatsApp               | ссылка в чате → отправить форму                                                      | whatsapp / chat               |
| M04 | iPhone, Safari, частный доступ | вставить ссылку в адресную строку → отправить форму                                  | partner / referral            |
| M05 | Android, Telegram              | ссылка в чате → встроенный браузер → отправить форму                                 | telegram / chat               |
| M06 | Android, Telegram              | ссылка в чате → открыть в Chrome до заполнения → отправить форму                     | telegram / chat               |
| M07 | Android, WhatsApp              | ссылка в чате → отправить форму                                                      | whatsapp / chat               |
| M08 | Android, Chrome, инкогнито     | вставить ссылку в адресную строку → отправить форму                                  | partner / referral            |
| M09 | Компьютер, Telegram Desktop    | ссылка в чате → браузер по умолчанию → отправить форму                               | telegram / chat               |
| M10 | Компьютер, WhatsApp Web        | ссылка в чате → новая вкладка → отправить форму                                      | whatsapp / chat               |
| M11 | iPhone, Telegram               | ссылка без меток в чате → отправить форму                                            | без метки                     |
| M12 | iPhone, Telegram               | встроенный браузер → заполнить форму → «Открыть в Safari» → отправить форму в Safari | граничный: связь не ожидается |

M12 — граничный сценарий: у встроенного браузера и Safari разные хранилища cookie, поэтому ожидаемый результат — заявка без сессии, учтённая отдельно.

## Что записать по каждому сценарию

Дата и время, модель устройства, версия ОС и приложения, собранная ссылка, появилось ли превью ссылки в чате, скриншот страницы «Спасибо».

## Проверка

```sql
SELECT l."email", l."sessionId", s."utmSource", s."utmMedium", s."utmCampaign", s."landingPath", n."status"
FROM "Lead" l
LEFT JOIN "Session" s ON s."id" = l."sessionId"
LEFT JOIN "Notification" n ON n."leadId" = l."id"
WHERE l."email" LIKE 'manual-%@control.navil.test'
ORDER BY l."createdAt";
```

Сценарий пройден, если у заявки есть сессия с параметром `nv_scn=manual-<номер>` в `landingPath`, метка сессии совпадает со ссылкой и есть уведомление. Превью-боты мессенджеров видны отдельно:

```sql
SELECT "startedAt", "client", "userAgent", "landingPath" FROM "Session"
WHERE "landingPath" LIKE '%nv_scn=manual-%' AND "client" = 'BOT';
```
